# 🎨 WebStudio - Modern Business Website

A beautiful, responsive business website built with **HTML and CSS**. This project showcases a professional portfolio site for a web design and development studio, featuring team information, services, and portfolio work.

🌐 **Live Demo:** [https://speedvlad.github.io/WebStudio/](https://speedvlad.github.io/WebStudio/)

---

## 📋 About This Project

WebStudio is a professional website demonstrating modern web design principles. It's built entirely with **HTML5 and CSS3** (no frameworks), showcasing:
- **Professional UI Design** - Clean, modern aesthetic with Ukrainian language support
- **Responsive Layout** - Perfect on mobile, tablet, and desktop
- **Semantic HTML** - Proper HTML structure for accessibility
- **Advanced CSS** - Flexbox, animations, and professional styling

The site presents a fictional web development studio but serves as an excellent template for any professional services business.

## 🚀 How to Use

### For Local Development
1. **Clone the repository**
   ```bash
   git clone https://github.com/SpeedVlad/WebStudio.git
   cd WebStudio
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server:
   ```bash
   python -m http.server 8000
   # Then visit http://localhost:8000
   ```

### For Deployment
The site is automatically deployed via GitHub Pages at: [https://speedvlad.github.io/WebStudio/](https://speedvlad.github.io/WebStudio/)

### Main Sections in `index.html`:
